Sobre o aplicativo

Fluente em Inglês é um projeto educacional de uso pessoal, desenvolvido para o aprendizado progressivo do inglês americano por meio de exercícios de conversação, compreensão, escrita, escuta e revisão.

O aplicativo funciona através do Telegram e utiliza o Google Drive para armazenar cópias de segurança do progresso do estudante.

Política de Privacidade

1. Dados utilizados

O aplicativo processa respostas escritas, mensagens de voz, identificadores do Telegram e informações relacionadas ao progresso educacional.

2. Uso do Google Drive

O acesso ao Google Drive é utilizado para criar, atualizar e recuperar arquivos de backup do aplicativo na conta autorizada.

3. Finalidade dos dados

Os dados são utilizados para acompanhar o aprendizado, corrigir exercícios e preservar o progresso educacional.

4. Compartilhamento

O projeto não comercializa dados pessoais. O Telegram é utilizado para comunicação, o Microsoft Edge TTS para gerar áudio e o Google Drive para backups. O reconhecimento de fala ocorre localmente por meio do Whisper.

5. Controle e exclusão

O usuário pode excluir seus backups diretamente no Google Drive e revogar a autorização nas configurações de segurança da sua conta Google.

6. Dados do Google

O uso das informações recebidas das APIs do Google deve respeitar a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.
